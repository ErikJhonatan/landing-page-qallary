# Qallariy · Página de presentación

Landing page académica de Qallariy, una calculadora de distribución de utilidades entre socios.

## Alcance

Sitio HTML/CSS que explica el proyecto, sus tecnologías y el equipo participante. La calculadora está en un repositorio separado: [Qallariy-App](https://github.com/ErikJhonatan/Qallariy-App).

## Estructura

`index.html`, `style/` y `assets/` contienen la página y sus recursos. Puede servirse como un sitio estático.

## Estado

La página contiene enlaces vacíos y un formulario de contacto sin un servicio de envío configurado en el HTML. Debe presentarse como una página académica en evolución. Conserva los créditos del equipo declarados en la página.
